# 부동산뉴스파인더 (안드로이드 앱)

부동산 **뉴스 · 정부 발표 · 커뮤니티 글**을 한곳에 모아 보여주고, 고른 글을 **스레드(Threads)용 요약 글 + 카드 이미지**로 만들어 주는 안드로이드 앱입니다.
수집은 클라우드(GitHub Actions)에서 돌아가므로 PC를 켜둘 필요가 없습니다.

```
 GitHub Actions (15분마다)                      안드로이드 앱 (APK)
 ┌────────────────────────────┐  posts.json  ┌───────────────────────────────────┐
 │ 뉴스 RSS · 정부 보도자료 ·  │ ───────────▶ │ 뉴스 / 정부·공공 / 커뮤니티 탭      │
 │ 커뮤니티 수집, 주제 태그,   │ (data 브랜치) │ 주제 칩 · 중요도 / 스레드 추천 정렬 │
 │ 중요도 · 스레드 추천 점수   │              │ 스레드용 요약 글 + 카드 이미지       │
 └────────────────────────────┘              │ 백그라운드 확인 → 알림              │
                                             └───────────────────────────────────┘
```

## 수집 소스 (`src/sources.js`)
- **언론:** 구글 뉴스 검색(부동산·청약·재건축·전월세·대출·실거래가), 한국경제, 매일경제, 연합뉴스, 동아일보, 경향신문, 한겨레, 아시아경제, 서울경제
- **정부·공공:** 국토교통부, 금융위원회, 기획재정부, 국세청 보도자료, 정책브리핑 정책뉴스 (정책브리핑 RSS)
- **커뮤니티:** 디시 부동산갤(개념글), 뽐뿌 부동산포럼, 클리앙 내집마련당

경제 전체 피드·타 부처 보도자료는 제목에 부동산 관련 낱말이 있는 글만 남깁니다.

## 점수
- **중요도:** 최신성 + 여러 매체가 같이 다룬 정도(제목 유사도) + 키워드 + 독자 관심도. 정부 발표는 가산. 커뮤니티는 게시판 안 상대 순위.
- **스레드 추천:** 사람들이 부동산 글에서 알고 싶어 하는 것(누가 대상인지, 언제부터인지, 얼마인지, 뭘 해야 하는지)과 구체적인 숫자가 제목에 있을수록 높고, 업계 동정·실적 기사는 낮습니다. (`src/topics.js`의 `threadPick`)

## 스레드용 만들기
글을 길게 누르거나 미리보기에서 "스레드용 만들기" → 원문을 읽고 요약(사용자의 Gemini/Groq 무료 키) → 카드 이미지(표지 + 핵심 정리)와 스레드 글 생성 → 갤러리 저장 또는 스레드 앱으로 보내기.
기사 화면은 캡처하지 않고 직접 그린 카드를 씁니다. 숫자는 원문에 있는 것만 쓰도록 지시하지만, 올리기 전에 원문과 대조하세요.

## 개발
```
npm ci && npm test            # 수집기 테스트
npm run crawl:demo            # 가짜 데이터로 out/posts.json 생성
cd android && ./gradlew assembleRelease                      # APK
cd android && ./gradlew testDebugUnitTest -PlocalJvmOnly      # 네트워크 제한 환경용 (화면 테스트 제외)
```
출시는 GitHub Actions > android > Run workflow 에서 `release`를 체크했을 때만 됩니다.
